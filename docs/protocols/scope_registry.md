# Реестр функций проекта

Этот файл фиксирует скоуп и статус функций проекта.

Статус функции определяет, можно ли начинать работу над ней.
Изменение статуса оформляется записью в этом реестре
и, при необходимости, в `07_decision_log.md`.

## Статусы

| Статус     | Значение                                                   |
| ---------- | ---------------------------------------------------------- |
| В скоупе   | Функция входит в текущий план                              |
| Вне скоупа | Функция не входит в текущий план, но может вернуться позже |
| Отложено   | Функция временно приостановлена                            |
| Отменено   | Функция окончательно исключена                             |

## Правила ведения

- Одна функция — одна запись.
- Для статусов «Вне скоупа», «Отложено» и «Отменено» обязательны причина и план возврата.
- Для статуса «В скоупе» причина и план возврата не требуются.
- Изменение статуса фиксируется с датой и ответственным.
- Изменение статуса не отменяет законы, запреты и требования безопасности.
- Важное решение об изменении скоупа дополнительно фиксируется в `07_decision_log.md`.
- Перед началом работы проверяются также `01_laws.md`, `02_prohibitions.md`, `04_conditions.md` и `09_entity_registry.md`.

## Как изменить статус

1. Проверить законы, запреты и влияние на данные.
2. Указать новую строку или изменить существующую.
3. Заполнить причину, план возврата, ответственного и дату.
4. При важном решении добавить запись в `07_decision_log.md`.
5. Проверить, что связанные сущности в `09_entity_registry.md`
