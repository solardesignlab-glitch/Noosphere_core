# Шаблоны протоколов

## Общее правило

Перед применением любого шаблона проверьте:

1. Статус функции в `scope_registry.md`.
2. Применимые законы в `01_laws.md`.
3. Запреты в `02_prohibitions.md`.
4. Условия применения в `04_conditions.md`.
5. При изменении сущностей — `09_entity_registry.md`.
6. При работе с источниками — `13_data_sources_map.md` и `14_truth_sources.md`.

Если статус функции неизвестен, указать `Unknown`.
Отсутствие записи в реестре не считается разрешением на работу.

Формат запроса и ответа агента определяется в `03_rules.md`.

## Исключения

Шаблон `ИСКЛЮЧЕНИЕ` — см. `06_change_process.md`.

Исключение фиксируется с указанием:

- правила;
- задачи;
- причины;
- срока действия;
- плана возврата к правилу.

Исключение не отменяет правило.
