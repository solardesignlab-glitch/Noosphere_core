\# Шаблоны протоколов



\## Отладка



```text

ПРОТОКОЛ: ОТЛАДКА

РЕЖИМ: ДИАГНОСТИКА

Симптом: ...

Где возникает: ...

Что уже пробовали: ...

Логи: ...

Ожидаемое поведение: ...

Ограничения: ...

```




\## Обязательные элементы ответа



Для каждого протокола ответ агента содержит:



```text

Диагноз → План → Действия → Проверка → Риски → Откат → Следующий шаг

```



\## Правило минимального шага



Если задача большая, агент делит её на этапы и предлагает только следующий проверяемый шаг.
