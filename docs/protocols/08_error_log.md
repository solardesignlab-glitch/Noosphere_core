# Журнал ошибок

Этот файл фиксирует повторяющиеся и значимые ошибки,
их причины, решения и уроки.

## Формат таблицы

| Дата | Ошибка | Причина | Решение | Урок | Статус |
|---|---|---|---|---|---|

## Правила ведения

- Одна строка — одна ошибка.
- Причина указывается только после проверки.
- Решение должно быть воспроизводимым.
- Ошибка считается закрытой, только если проверка подтвердила решение.

## Статусы

| Статус | Значение |
|---|---|
| Open | Ошибка обнаружена |
| Investigating | Ведётся диагностика |
| Fixed | Решение применено и проверено |
| Recurred | Ошибка повторилась |
| Won't fix | Решение отложено |
