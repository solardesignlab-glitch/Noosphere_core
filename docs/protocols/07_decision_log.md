# Журнал решений

Этот файл фиксирует важные решения проекта.  
Каждое решение должно быть воспроизводимым и иметь причину.

## Правила ведения

- Одна запись — одно решение.
- Решение фиксируется до или сразу после внедрения.
- Если решение изменилось — создаётся новая запись, а старая получает статус `Deprecated`.
- В записи всегда указывается способ отката.
- Решения, затрагивающие статус функции, синхронизируются с `scope_registry.md`.

## Статусы

| Статус | Значение |
|---|---|
| Proposal | Предложено |
| Agreed | Согласовано, но не внедрено |
| Active | Решение действует |
| Deprecated | Отменено или заменено |
