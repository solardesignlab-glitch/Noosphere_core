\# Протокол передачи между агентами



\## Формат задачи



```text

ОТ: Аналитик

КОМУ: Исполнитель

ПРОТОКОЛ: <тип>

ЗАДАЧА: ...

ФАКТЫ: ...

ОГРАНИЧЕНИЯ: ...

КРИТЕРИЙ ПРИЁМКИ: ...

РИСКИ: ...

ОТКАТ: ...

```



\## Формат результата



```text

ОТ: Исполнитель

КОМУ: Ревьюер

СТАТУС: Ready for review

ИЗМЕНЕНИЯ: ...

ПРОВЕРКА: ...

ЛОГИ: ...

ОТКАТ: ...

```



\## Формат вердикта



```text

ОТ: Ревьюер

КОМУ: Координатор

ВЕРДИКТ: Approve / Changes requested

ПРИЧИНА: ...

РИСКИ: ...

СООТВЕТСТВИЕ ПОЛИТИКЕ: Да / Нет

```



\## Правила передачи



\- Одна передача — одна задача.

\- В задаче всегда есть критерий приёмки.

\- В результате всегда есть проверка и откат.

\- Ревьюер обязан проверить соответствие политике.

\- При статусе `Changes requested` задача возвращается исполнителю.
