\# Карта источников данных



\## Источники проекта



| Источник | Назначение | Доступ |

|---|---|---|

| Git-репозиторий | Код, конфигурация, документация | Чтение / запись через исполнителя |

| EspoCRM metadata | Сущности, поля, связи, макеты | Чтение / изменение через протокол CRM |

| База данных | Фактические данные и схема | Read-only для аналитика |

| Docker-логи | Ошибки, состояние сервисов | Чтение |

| API-ответы | Проверка работоспособности | Чтение |

| Журнал решений | Архитектурные решения | Чтение / запись архивариусом |

| Журнал ошибок | Повторяющиеся проблемы | Чтение / запись архивариусом |

| Реестр сущностей | Одна модель истины | Чтение / изменение через протокол данных |



\## Правило использования



\- Аналитик сначала смотрит в фактическое состояние системы.

\- Затем сверяет с метаданными и протоколами.

\- Затем формирует гипотезы.

\- Не использует непроверенные внешние источники как факт.



\## Обязательные источники для анализа



| Тип задачи | Минимальные источники |

|---|---|

| Отладка | Логи, команда воспроизведения, конфигурация |

| Модель данных | Метаданные, БД, реестр сущностей |

| CRM | Метаданные, макеты, скриншот |

| Архитектура | Код, конфигурация, журнал решений |

| Релиз | Git-статус, логи, план отката |
