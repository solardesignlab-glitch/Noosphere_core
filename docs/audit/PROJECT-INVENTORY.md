# PROJECT-INVENTORY — Атмосфера OS

Версия: 1.0 (первый проход, факты верифицированы)
Дата: 2026-11-13
Метод: все факты получены командами в терминале, не из документов.

## 1. Цели

- Бизнес: экосистема управления бизнесом в сфере услуг — CRM, контент-движок, обучение, сайт.
- Продукт: MVP Атмосфера OS — базовое ядро, пакет Beauty, AI-ассистент, дашборд владельца.
- Коммерция: первые платящие пилоты, подписки покрывают ФОТ.
- Критерии MVP: 10 платящих пилотов, запуск до 30 дней, churn 6 мес ниже 5 процентов, NPS выше 40, ROI-кейс у 5 клиентов, выручка покрывает ФОТ.
Источник: vision_master_document.md.

## 3. Карта структуры

- apps/api — Backend API (Node, Express, mysql2). Живой.
- apps/web-archive — архив старой итерации фронтенда.
- frontend — живой фронт (React, Vite, 8 страниц).
- services/telegram — Python-бот, Docker-контейнер ucp_telegram. Живой.
- services/worker, services/database, services/redis — заготовки, назначение уточнить.
- espocrm, espocrm-custom, custom — CRM-слой, контейнер ucp_espocrm на 8081. Живой.
- docs — протоколы 00-15, продукт, аудит. Живой слой управления контекстом.
- backend-archive, backups, new-react-project-archive — архивы.
- Корень — мусор: patch-файлы, контекстные дампы, docs.rar. Чистить.

## 4. Карта инструментов

Node.js + Express + mysql2 — Backend API.
React + Vite — фронтенд.
Python (aiogram) — Telegram-бот.
PHP + EspoCRM — CRM-слой.
Docker Desktop — контейнеры: telegram, espocrm, redis, database.
Ollama — локальный AI, единственный провайдер (через OpenAI-совместимый API и через прямой fetch).

- Открытый риск: на 3306 два слушателя — локальная MariaDB и контейнер ucp_database.
  Куда реально пишет бэкенд — не установлено. Проверка: SELECT VERSION() через путь подключения.
- Кандидаты в источник истины: та база, в которой лежат рабочие таблицы клиентов и услуг.

## 7. Аномалии и открытые риски

1. Два слушателя на 3306 — возможна запись не в ту базу. Приоритет высокий.
2. Четыре node-процесса из аудита — возможны дубли бэкенда. Проверить после развязки портов.
3. Комментарии в .env поломаны (кодировка не UTF-8).
4. Пароль БД засветился в переписке — сменить при удобной минуте.
5. Корень замусорен одноразовыми файлами — почистить перед первым коммитом.
