# ADR-0001: Вести архитектурные решения через ADR

## Status
Accepted

## Date
2026-11-03

## Context
Atmosfera — multi-tenant B2B2C платформа.
Решения принимаются быстро, но теряется контекст.

## Decision
Вести ADR в docs/adr/.
Один ADR = одно решение.

## Consequences
### Positive
- Сохраняется история решений.
### Negative
- Требуется дисциплина.
### Risks
- ADR перестают обновлять.
