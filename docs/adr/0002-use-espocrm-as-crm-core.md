# ADR-0002: Использовать EspoCRM как CRM-ядро

## Status
Accepted

## Date
2026-11-03

## Context
Нужна CRM-основа: клиенты, специалисты, записи.

## Decision
EspoCRM как CRM-ядро и master data на 3–6 месяцев.

## Consequences
### Positive
- Быстрый старт.
### Negative
- PHP-стек.
### Risks
- Vendor lock-in.
