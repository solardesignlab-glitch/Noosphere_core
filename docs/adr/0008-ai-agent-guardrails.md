# ADR-0008: Guardrails для AI-агентов

## Status
Accepted

## Date
2026-11-03

## Context
Агенты могут выполнять действия с данными.

## Decision
Scoped identity, policy-as-code, Action Broker, human-in-the-loop.

## Consequences
### Positive
- Безопасные агенты.
### Negative
- Сложнее разработка.
### Risks
- Agent sprawl.
