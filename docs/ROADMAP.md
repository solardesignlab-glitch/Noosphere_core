# Порядок разработки MVP

## Неделя 1

1. Развернуть Docker Compose.
2. Настроить EspoCRM и администратора.
3. Создать API-пользователя.
4. Настроить резервные копии.
5. Создать сущности Service, Master, Appointment.
6. Настроить макеты списков и карточек.

## Неделя 2

1. Создать тестовые услуги, мастеров и клиентов.
2. Проверить создание записи через API.
3. Добавить проверку конфликта времени.
4. Развернуть Telegram-сервис.
5. Подключить webhook Telegram.
6. Реализовать создание лида из сообщения.

## Неделя 3

1. Отправка подтверждения записи.
2. Кнопки «Подтвердить» и «Перенести».
3. Обновление статуса записи.
4. Напоминание за 24 часа.
5. Создание задачи администратору при запросе переноса.

## Неделя 4

1. Импорт клиентов из CSV.
2. Базовый отчёт по записям и no-show.
3. Роли: собственник, администратор, мастер.
4. Логирование действий.
5. Подключение первого пилотного клиента.

## Критерий готовности

Продукт готов к пилоту, если администратор может создать запись, клиент подтверждает её в Telegram, статус обновляется в CRM, а собственник видит записи и no-show.
