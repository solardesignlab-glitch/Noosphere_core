# UCP MVP — AtmoOS: дорожная карта

UCP — модульная ERP-платформа для beauty/salon-бизнеса.

EspoCRM используется как CRM-модуль: клиенты, лиды, сделки и коммуникации.  
UCP Core — управляющий слой платформы: организации, роли, записи, услуги, мастера, аналитика, агенты и автоматизации.

## Текущий статус

- Backend: Node.js + Express + MySQL-совместимый пул (`mysql2/promise`).
- Frontend: React + Vite, `apps/web`.
- Авторизация: JWT, `requireAuth` в `apps/api/auth.js`.
- Multi-tenant: `tenantContext` берёт `organizationId` только из JWT.
- Frontend использует `backendRequest`; токен хранится в `localStorage` под ключом `atmosfera_token`.
- Локальный запуск без Docker: `start-dev.bat` запускает API и WEB в отдельных окнах.
- Docker: `ucp_database`, `ucp_espocrm`, `ucp_redis`.
- Backend API: `http://localhost:4000`.
- Frontend: `http://localhost:5173`.

## Архитектурные принципы

1. `organizationId` всегда берётся из JWT.
2. Клиент не может передавать `organizationId` в API.
3. Для списков используется `WHERE organization_id = ?`.
4. Для обновления и удаления используется `WHERE id = ? AND organization_id = ?`.
5. SQL — только параметризованный.
6. Секреты, логи и резервные копии не хранятся в Git.
7. UCP — ядро ERP; EspoCRM — подключаемый CRM-модуль.
8. Доступ к данным и агентам определяется ролью пользователя.
9. Новые интерфейсы собираются из единой UI/UX-системы.
